### 🎯 Aim
Implement user registration, login, salted bcrypt password hashing, JWT token issuance, and authorization middleware.

---

### 📝 Problem Statement & Description
Protects private task endpoints with authMiddleware, isolates user tasks preventing cross-user data leakage (403 Forbidden).

---

### 🛠️ Technologies Used
- JWT (jsonwebtoken), bcryptjs, Express Middleware, React AuthContext

---

### 🏃 How to Run This Practical
```bash
cd backend && npm test
# Verifies authentication, login, and 403 cross-user isolation
```
