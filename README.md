### 🎯 Aim
Develop a structured REST API for task management with CRUD endpoints, request logging middleware, and centralized error handling.

---

### 📝 Problem Statement & Description
Implements modular Express routing (/api/health, /api/tasks), custom latency/status logger middleware, and centralized error handling.

---

### 🛠️ Technologies Used
- Node.js 20, Express.js 4.21, CORS, Dotenv

---

### 🏃 How to Run This Practical
```bash
cd backend
npm install
npm run dev
# Health check: http://localhost:5000/api/health
```
